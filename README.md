# NEXORA TI

**Proyecto Intermodular – 2.º ASIR**  
**Alumno:** Izan García Caballero  
**Curso:** 2026-2027

## 1. Descripción del proyecto

Nexora TI es un proyecto de empresa de servicios informáticos orientado a ofrecer soluciones tecnológicas a pequeñas y medianas empresas.

Su objetivo es proporcionar servicios de infraestructura, virtualización, redes, almacenamiento, seguridad y automatización, apostando por la eficiencia energética y el soporte de proximidad.

## 2. Objetivo de la infraestructura

Diseñar una infraestructura informática organizada, segura y escalable que permita alojar y administrar los servicios de una pequeña empresa.

Se busca facilitar la gestión de los sistemas, proteger la información, automatizar tareas y disponer de mecanismos de monitorización y copias de seguridad.

## 3. Tecnologías utilizadas

- **Proxmox VE:** virtualización de servidores.
- **Debian 12:** sistema operativo de los servidores Linux.
- **Nginx:** servidor web y proxy inverso.
- **MariaDB:** sistema gestor de bases de datos.
- **Docker:** ejecución de aplicaciones mediante contenedores.
- **Ansible:** automatización de configuraciones.
- **OPNsense:** firewall y seguridad de red.
- **Zabbix:** monitorización de sistemas y servicios.
- **Proxmox Backup Server:** gestión de copias de seguridad.
- **Git y GitHub:** control de versiones y almacenamiento del proyecto.

## 4. Estructura del repositorio

- `playbooks/`: automatización mediante Ansible.
- `roles/`: funciones organizadas por servicios.
- `variables/`: variables de configuración.
- `plantillas/`: plantillas de configuración.
- `inventario/`: inventario de equipos y servidores.
- `documentacion/`: documentación técnica.
- `README.md`: información general del proyecto.

## 5. Estado del proyecto

La estructura del repositorio se establece como base para organizar el desarrollo de Nexora TI. Los archivos de configuración, automatizaciones y servicios se incorporarán progresivamente durante el desarrollo del proyecto.
